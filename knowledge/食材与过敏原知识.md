# MenuLens 食材与过敏原知识库

> 本文档补充 RAG 检索的食材、过敏原与营养知识，供 AI 小助手回答「能不能吃」「含什么」「怎么搭配」等问题。

## 八大常见过敏原

| 过敏原 | 常见食物来源 | 说明 |
|---|---|---|
| 花生 | 宫保鸡丁、花生酱、花生油、沙茶酱 | 最凶险的过敏原之一，可能引发严重过敏反应 |
| 坚果 | 腰果、核桃、杏仁、松子 | 常出现在甜点、沙拉、炒菜中 |
| 海鲜（鱼） | 各种鱼类、鱼露、鱼高汤 | 鱼类过敏常伴随海鲜类交叉反应 |
| 甲壳类 | 虾、蟹、龙虾、贝类 | 冬阴功、寿司、海鲜料理常见 |
| 乳制品 | 牛奶、奶酪、黄油、奶油 | 西式酱汁、甜点、奶茶常见 |
| 麸质 | 小麦、大麦、黑麦、面筋 | 面食、面包、酱油、啤酒常见 |
| 蛋 | 鸡蛋、蛋黄酱、蛋糕、裹粉 | 白切鸡可能含蛋、炸物裹粉常含蛋 |
| 大豆 | 豆腐、酱油、豆豉、味噌、豆浆 | 亚洲菜几乎无处不在 |

**注意**：过敏原信息来自菜单识别与知识库，可能有遗漏。涉及过敏原时，AI 助手必须提示用户「建议向服务员确认」，不得给出诊断性结论。

## 口味与辣度分级说明

| 辣度等级 | 数值范围 | 代表菜品 | 说明 |
|---|---|---|---|
| 不辣 | 0 | 白切鸡、清蒸鱼、番茄炒蛋 | 完全无辣，适合清淡口味 |
| 微辣 | 0.1-0.3 | 干炒牛河、蒜蓉时蔬 | 只有隐约辣味 |
| 中辣 | 0.4-0.6 | 宫保鸡丁、蒜泥白肉 | 明显辣味，大多数可接受 |
| 重辣 | 0.7-1.0 | 麻婆豆腐、水煮鱼、冬阴功 | 麻辣厚重，重口味爱好者 |

## 点单搭配原则

1. **荤素搭配**：荤菜占比约 60%，素菜约 30%，主食或汤约 10%。
2. **味型错开**：避免一桌全是重辣或全是清淡，酸辣、鲜香、清甜交替更有层次。
3. **预算控制**：主菜占预算大头，素菜和汤压成本，主食管饱。
4. **忌口优先**：过敏原和忌口必须硬过滤，任何含忌口成分的菜都不出现在方案里。
5. **人数匹配**：人均 1-1.5 份量，2 人约 3-4 道菜，4 人约 6-7 道菜。

## 常见菜品问答速查

**「麻婆豆腐能不能做成不辣的？」**
可以。去掉豆瓣酱和花椒粉，改用甜面酱 + 少量番茄酱调味，做成甜口版本，小孩也能吃。

**「宫保鸡丁为什么叫宫保？」**
源自清代官员丁宝桢的「宫保」头衔，他喜食这道花生鸡丁，后人以「宫保」命名。

**「白切鸡怎么判断熟没熟？」**
用筷子插入鸡腿最厚处，没有血水流出即熟。浸熟后立刻冰水激皮，皮才脆。

**「冬阴功的酸味来自什么？」**
主要来自青柠汁和柠檬叶，辣味来自辣椒，香来自香茅和南姜。

**「干炒牛河为什么容易粘锅？」**
河粉本身含淀粉，锅不够热或油不够就粘。师傅秘诀是「锅要烧到冒烟再下油」。

## 营养成分与人群建议

| 人群 | 点单建议 | 需要避开的菜 | 原因 |
|---|---|---|---|
| 儿童 | 番茄炒蛋、上汤时蔬、可乐鸡翅（去皮）、味噌汤 | 水煮鱼、麻婆豆腐（重辣版）、泰式冬阴功 | 辣度过高刺激肠胃，鱼刺风险 |
| 孕妇 | 白切鸡、清蒸海斑鱼、上汤时蔬、蒜蓉炒时蔬 | 生食类寿司、酒香类菜、未熟透的肉 | 需避免生食与酒精，鱼类选低汞品种 |
| 三高（高血压 / 高血脂 / 高血糖） | 清蒸鱼、白灼类、蒜蓉时蔬、味噌汤少盐 | 豉汁排骨、蒜泥白肉、可乐鸡翅、干炒牛河 | 高油高盐高糖，酱汁钠含量高 |
| 痛风 / 高尿酸 | 番茄炒蛋、上汤时蔬、蒜蓉炒时蔬 | 海鲜类、浓肉汤、豆制品（适量限制） | 嘌呤与果糖影响尿酸代谢 |
| 减脂期 | 白切鸡（去皮）、清蒸鱼、焯水时蔬 | 干炒牛河、可乐鸡翅、蒜泥白肉、水煮鱼（油多） | 主食油量与糖油混合物热量高 |
| 素食者 | 上汤时蔬换成素高汤、麻婆豆腐（素版）、番茄炒蛋（蛋奶素） | 所有含肉、含鱼露、含蚝油的菜 | 蚝油、鱼露、虾米常被忽略 |

**通用原则**：粤菜清蒸、白灼整体比重辣重油菜更适合控制油盐；但「上汤」类菜的高汤往往含火腿与鸡骨，严格素食者要问清楚。

| 菜 | 原辣度 | 去辣改法 | 改造后风味 |
|---|---|---|---|
| 麻婆豆腐 | 重辣 | 去豆瓣酱与花椒粉，用甜面酱 + 少量番茄酱 | 甜咸微鲜，小孩可吃 |
| 宫保鸡丁 | 中辣 | 干辣椒减半、不放辣椒油 | 酸甜荔枝口保留 |

## 酒水与菜品搭配禁忌

- **白切鸡 + 啤酒**：粤式说法认为同食偏「湿」，肠胃弱的人易不适。
- **海鲜 + 大量啤酒**：增加嘌呤负荷，痛风人群要避开。
- **重辣菜 + 冰饮**：刺激肠胃，敏感人群建议配温茶。
- **清蒸鱼 + 浓香型白酒**：酒味会盖掉鱼的鲜甜，建议清淡酒或茶。

## 常见问答补充

**「寿司里的芥末算辣吗？」**
算。芥末的辣来自异硫氰酸酯，与辣椒素不同，刺激鼻腔而非舌头，且挥发快、不持久。

**「味噌汤是素食吗？」**
不一定。传统味噌汤用鲣鱼高汤（dashi）打底，严格素食者需点「昆布高汤」版本。

**「冬阴功能不能不加虾？」**
可以。可要求换成鸡肉或纯菌菇版，酸辣底味不变，但虾的鲜甜会减弱。

**「干炒牛河和湿炒牛河有什么区别？」**
干炒不带汁、河粉根根分明、锅气足；湿炒带芡汁、口感滑。干炒更考验师傅火候。

**「可乐鸡翅的甜味是糖还是可乐？」**
两者都有。可乐本身含糖，收汁后糖分浓缩，所以热量比看上去高。

**「为什么粤菜馆的清蒸鱼比红烧鱼贵？」**
清蒸对鱼的鲜度要求最高，不新鲜的鱼无法用重味掩盖，所以选料成本更高。
